# デザイントークン（Figma との対応）

色・余白・文字の定義は Figma「家計簿」（`k99TXVIrWbQ9YYSNBnbaFW`）が正で、
`src/tokens.css` はそれと同じ名前・同じ値で持つ。

| 種類             | Figma                                                                                                            | tokens.css                                                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 色（基礎）       | 「基礎カラー」コレクション（水色/100 など。直接は使わない）                                                      | 持たない                                                                                                                             |
| 色（役割）       | 「補助カラー」コレクション（基本/文字 など。値は基礎カラーを参照）                                               | `--color-*`                                                                                                                          |
| 余白の段階       | 「サイズ」の 余白/50〜800（100 = 4px）                                                                           | `--space-50`〜`--space-800`                                                                                                          |
| 余白の役割       | 「サイズ」の 余白（役割）/*（値は段階を参照）                                                                    | `--gap-inline`・`--gap-stack`・`--gap-section`・`--padding-control-x`・`--padding-card`・`--padding-page`                            |
| 大きさ・角丸・線 | 「サイズ」の 大きさ/部品の高さ・部品の最小幅・絞り込みの幅・角丸/100・200・線/枠線・フォーカス・フォーカスの間隔 | `--size-control`・`--size-control-min`・`--size-filter`・`--radius-*`・`--border-width`・`--focus-ring-width`・`--focus-ring-offset` |
| 文字             | 文字スタイル 文字/本文・本文（1行）・補足・小見出し・見出し・金額                                                | `--text-*`（対応表は `scripts/check-tokens.mjs`）                                                                                    |
| 影               | 影のスタイル 影/浮き上がり                                                                                       | `--shadow-raised`                                                                                                                    |

値は SDS の 4px 刻みや文字の大きさを参考にしているが、名前と定義はアプリのもの（SDS のライブラリの変数は参照しない）。

## 役割の変数の使いどころ

| 変数                  | 使いどころ                                                                           |
| --------------------- | ------------------------------------------------------------------------------------ |
| `--gap-inline`        | 横に並ぶ小さな要素の間（アイコンと文字、ページ番号、表の操作、絞り込みのプルダウン） |
| `--gap-stack`         | 画面の要素の縦の並び（年月の選択・合計・表・カード）と画面の大枠                     |
| `--gap-section`       | まとまり同士の間（フォームの項目、ダイアログの見出し・本文・操作）                   |
| `--padding-control-x` | 入力欄・プルダウン・表のセルの左右                                                   |
| `--padding-card`      | カード・サイドバー・内訳の内側                                                       |
| `--padding-page`      | メインコンテンツ（右側の白い枠）の内側                                               |
| `--size-control`      | 入力欄・プルダウン・表の行・合計行の高さ（40px）                                     |
| `--size-control-min`  | 入力欄・プルダウン・ボタンの最小幅（120px）                                          |
| `--size-filter`       | 絞り込みのプルダウン（年・月・分類・属性名）の幅（160px、幅 768px 以上）             |
| `--radius-100`        | フォーカスの枠・小さい部品                                                           |
| `--radius-200`        | カード・入力欄・ボタン・ダイアログ                                                   |

## Figma を変えたとき

1. `scripts/export-figma-tokens.js` の中身の後ろに `return await exportFigmaTokens();` を付けて、
   Figma で実行する（Figma の MCP の use_figma など）。
2. 返ってきた JSON を `design-tokens/figma-tokens.json` に保存する。
3. `pnpm --filter @home-expense/ui lint:tokens` で照合し、ずれた `src/tokens.css` を直す。

`scripts/check-tokens.mjs` の照合のしかた:

- 色・サイズ: Figma の変数のコード名（WEB）= CSS 変数名。値と、役割がどの段階を参照しているかを突き合わせる。
- 文字・影: Figma のスタイルにはコード名がないため、スクリプトの中の対応表（`TEXT_STYLES`・`EFFECT_STYLES`）で突き合わせる。
- `tokens.css` にあって Figma にない変数も、ずれとして扱う。

`lint:tokens` は `pnpm lint`（CI）でも動き、ずれがあると失敗する。

## 決まりごと

- 色を足すときは、Figma の補助カラーに変数を作り（値は基礎カラーを参照、コード名 WEB に `var(--color-…)`）、
  tokens.css にも同じ名前で足す。
- 名前: 段階は数字（`--space-400` = 16px）、役割は用途の名前（`--gap-stack`）。サイズ記号（xs・s・m）は使わない。
- 余白は、まず役割を使い、当てはまらない細部だけ段階を直接使う。段階の外の値（6px・13px など）は使わない。0 は変数にせず `0` と書く。
- 変数にするのは、複数の部品で同じ意味で使う値だけ。1 つの部品の中だけの寸法（サイドバーの幅など）は、CSS にコメントで Figma の根拠を書いて直接書く。
- Figma のフォーカスの線は影 2 枚（広がり 2 = 間隔、4 = 間隔＋太さ）で描く。変数を付けられるのは間隔の影だけ。入力欄・プルダウンは、枠線をフォーカスの色にし、内側の影（広がり 1）を 1 枚足す。
  Figma でも同じく、役割の変数（余白（役割）/*）を優先して付ける。
- 文字スタイルは 文字/* の 6 種類だけを使う。増やすときは `check-tokens.mjs` の対応表にも足す。
- 文字/金額の「数字: 等幅」は Figma の API から設定・確認できないため、Figma の文字スタイルで手で設定しておく。
